# Reference source provenance

The editable Astro reference application, shared canonical content, examples, dashboards, scientific demo, and family mark originate in `k3jph/design-workbench` commit `4a1b0991c970f4c182234273c01f9e97d35992cc` under `examples/astro-slice`, `examples/page-archetypes`, and `examples/jekyll/martlet`. They are copied as source to allow builds without the workbench. Relative imports have been adjusted for this repository and source-profile CSS uses the published core package. The original project and source carry the MIT license.

This is a candidate extraction; cross-framework behavior, accessibility, full archive integration, and publication have not yet been verified.
